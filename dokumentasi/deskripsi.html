Login
AdminPetugasPeminjam   Route: /login   POST

Autentikasi pengguna, verifikasi kredensial, dan redirect ke dashboard sesuai role.

Input
#VariabelTipeKeterangan
1emailStringAlamat email terdaftar (required, format email valid)
2passwordStringKata sandi pengguna (required, min 8 karakter)
Proses
#Langkah
1Validasi format email dan password tidak kosong
2Cari user berdasarkan email di tabel users
3Bandingkan password dengan hash bcrypt (Hash::check())
4Cek status is_active user
5Buat session Laravel dan simpan data role
6Catat log aktivitas aksi = 'login'
7Redirect ke dashboard sesuai role (admin / petugas / peminjam)
Output
#VariabelKeterangan
1sessionSession berisi id, name, role pengguna
2redirect URLDashboard sesuai role pengguna
3log_aktivitasRecord baru aksi = 'login'
4pesan errorJika gagal: notifikasi email atau password salah

Pengembalian Alat & Denda
PetugasAdmin   Route: /pengembalian/{id}   POST

Pemrosesan pengembalian alat. Denda dihitung via MySQL function, stok_tersedia ditambah via trigger. Menggunakan Stored Procedure dengan START TRANSACTION, COMMIT, dan ROLLBACK.

Input
#VariabelTipeKeterangan
1tgl_kembaliDateTanggal aktual pengembalian (required)
2kondisi_akhir[]Array EnumKondisi tiap alat: baik / rusak ringan / rusak berat
3keteranganTextCatatan kondisi alat (opsional)
Proses
#Langkah
1Validasi status peminjaman = dipinjam / menunggu_konfirmasi
2Update kondisi_akhir di tabel detail_peminjaman
3Panggil Stored Procedure proses_pengembalian()
4SP: START TRANSACTION → hitung hari_terlambat (DATEDIFF)
5SP: Panggil Function hitung_denda(hari) → denda = hari × Rp 5.000
6SP: INSERT ke tabel pengembalian
7SP: UPDATE status peminjaman = dikembalikan → COMMIT
8TRIGGER MySQL otomatis menambah stok_tersedia alat
9Jika error: EXIT HANDLER → ROLLBACK
Output
#VariabelKeterangan
1pengembalian (table)Record baru data pengembalian
2dendaNominal denda (Rp 0 jika tepat waktu)
3alat.stok_tersediaBertambah otomatis via trigger
4peminjaman.statusDiperbarui: dikembalikan

#VariabelKeterangan
1tabel laporanData rekap peminjaman sesuai filter
2file PDFLaporan siap cetak (opsional, format A4 landscape)
